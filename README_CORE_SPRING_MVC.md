# Core Spring MVC (classic, no Spring Boot)

This folder will contain a minimal "core Spring MVC" clone-style project that demonstrates the **classic** Spring MVC setup:

- Maven WAR project
- `web.xml` registering `DispatcherServlet`
- `HandlerMapping`/`HandlerAdapter` handled by `spring-webmvc`
- `@Controller` + `ModelAndView`/view rendering

See the generated directory structure in:
- `DOCS/CORE_SPRING_MVC_DIRECTORY_STRUCTURE.md`
